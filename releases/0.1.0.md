# Marquee 0.1.0, the first beta

Marquee is one small self-hosted app for your movie, TV and music library. It does the jobs of Sonarr, Radarr,
Lidarr, Bazarr, Prowlarr and Seerr in a single program, and plugs into the apps you already run: qBittorrent,
Deluge or SABnzbd to download, Jellyfin, Emby or Plex to watch. This is the first release people can run end to end.
It is a **beta**: it works, it is young, and it has rough edges.

## What you get

- **One program.** A static binary with the web interface inside, for Linux (amd64, arm64, armv7), Windows (amd64)
  and macOS (arm64), and a tiny container image (`FROM scratch`) for amd64, arm64 and arm/v7.
- **Movies, TV and music.** Search, follow, and see what is on disk, what is missing and what airs next. Movies
  use your TMDB key; shows (TVmaze) and music (MusicBrainz) need none.
- **Requests.** Invite friends. They ask for a movie, show or artist in HD or 4K; a 4K ask is a separate copy in its
  own folder. Asks can wait for your yes, go through on their own for people you trust, and are limited per person per
  week. Plex watchlists, yours and your friends', turn into asks on their own.
- **Release finding with reasons.** Add Torznab or Newznab feeds, or import them from Prowlarr or Jackett. Every release
  is ranked by your quality rules, and Marquee says in plain words why it chose one and turned another down.
- **Download and import.** Sends the pick to your download app, follows it live, then checks, unpacks, renames and
  hardlinks (or moves) it into the library, and tells your media server to rescan. A bad release is blocklisted and
  the next best is tried.
- **Subtitles and music.** Subtitles by language rule; albums grabbed, tagged and imported.
- **Claude.** A built-in MCP server lets Claude Code search, look at your library and ask for titles, as you.
  It can never approve, delete or change settings.
- **Alerts** to Discord, ntfy, Gotify, Telegram, Pushover, email or a webhook.
- **Private.** No telemetry, no update check, no relay. Every outside host is listed in `docs/privacy.md`.
- **Small.** The Linux amd64 download is about 7 MB; `marquee.exe` is about 16 MB.

## Get it

- **Docker:** `docker run -d -p 6464:6464 -v marquee-config:/config -v /srv/media:/data ghcr.io/baileypillon/marquee:0.1.0`
  or use `deploy/compose.yaml`.
- **Windows, Linux, macOS:** download the archive for your system below, check it against `SHA256SUMS`, unpack and run
  `marquee`. Add `-config <folder>` to say where its files go.

Open <http://localhost:6464>. **The first person to open it becomes the owner**, so do that first. The install guide is
`docs/install.md`.

**Back up `marquee.key`** (in the config folder). It encrypts the keys and passwords you save in Settings, and they
cannot be recovered without it.

## Known limits

This is a beta. Things to know:

- **Plex watchlists** were built from Plex's public documentation and have not yet been run against the live Plex service.
  If linking or checking fails, please report what you see.
- **Download apps:** qBittorrent, Deluge and SABnzbd. Transmission and NZBGet are not supported yet. Path rules for
  download apps (when an app sees your files at a different path) can only be set through the API for now.
- **Unsigned programs.** Windows SmartScreen and macOS Gatekeeper will warn about the downloads. The macOS build has not
  been tested on a Mac.
- **No built-in scrapers** and no playback, on purpose: you bring your own sources, and your media server plays the files.
- **Claude** connects with an API key sent as a Bearer header (Claude Code does this). There is no OAuth sign-in yet.
- **Reverse proxies:** put Marquee at the root of a host name; sub-paths are not supported.

## Upgrading

There is nothing to upgrade from yet. From now on: back up the config folder, replace the program (or pull the new image) and
start it; the database upgrades itself. Do not run an older version against a database a newer one has upgraded.
